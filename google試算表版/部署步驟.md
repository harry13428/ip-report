# Google 試算表版 部署步驟（KK 做一次，約 3 分鐘）

1. 用電腦開 https://sheets.new → 會開一張新的 Google 試算表，左上角把名字改成「IP週報」
2. 上方選單 **擴充功能 → Apps Script**，會開一個新分頁
3. 把編輯區裡原本的幾行字全部刪掉，把 `Code.gs` 這個檔案的內容整份貼進去，按上方的 💾 儲存
4. 右上角藍色 **部署 → 新增部署作業**
   - 左邊齒輪「選取類型」選 **網頁應用程式**
   - 「執行身分」選 **我**
   - 「誰可以存取」選 **所有人**
   - 按 **部署**
5. 會跳出「需要授權」→ 按 **授權存取權** → 選你的 Google 帳號 → 出現「Google 尚未驗證這個應用程式」→ 按左下角 **進階** → 按 **前往 IP週報（不安全）** → 按 **允許**
   （這是 Google 對所有自己寫的小程式都會顯示的固定警告，程式只會讀寫這一張試算表）
6. 出現「網頁應用程式 網址」，按 **複製**，把那串 `https://script.google.com/macros/s/…/exec` 貼給 Claude

之後：試算表會自動多出「回報」「剪輯師」兩個分頁，就是所有人的資料；主管可以直接開試算表看。
