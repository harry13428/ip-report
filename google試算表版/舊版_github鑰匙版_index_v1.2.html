主管可以直接複製整週彙整貼到群組或文件。

第一次使用：三步就好

填你的名字
大家會用這個名字看到你的回報。之後不要改名，改了會變成另一個人。
貼上鑰匙
鑰匙由 KK 傳給你（LINE 貼過來）。只要貼一次，這台手機／電腦會記住。
測試連線
出現「連線成功」就完成了，回到「我的回報」開始填。

專用連結（推薦這樣開）

這個連結裡已經包含你的名字和鑰匙，用它開 App 就不用再貼鑰匙。存成書籤或「加入主畫面」，以後點它就好。
⚠️ 這個瀏覽器不會記住設定，請一定用下面的專用連結開 App。
要給同事：打他的名字，複製給他的連結，用 LINE 私訊傳。他點開就能用。

鑰匙怎麼拿（KK 看這裡）

整個團隊共用一把鑰匙，做一次就好。
  1. 用電腦開 github.com/settings/personal-access-tokens/new（登入 harry13428）
  2. Token name 打「IP週報」；Expiration 選最長的
  3. Repository access 選「Only select repositories」→ 只勾 ip-report-data
  4. Permissions → Repository permissions → Contents 改成 Read and write
  5. 最下面按 Generate token → 把 github_pat_… 整串複製，貼到上面第 2 步，並傳給同事

資料放在哪

所有人的回報都存在 GitHub 私人倉庫 ，只有拿到鑰匙的人看得到。每次按「儲存並上傳」就會同步給大家。
